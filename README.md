# منظومة ثانوية أبي أيوب الأنصاري

شؤون الطلاب والتوجيه وحصص الانتظار. الخادم FastAPI، والقاعدة PostgreSQL (دائمة) أو SQLite (محلياً)، والواجهة صفحة واحدة (`static/index.html`) بهوية المدرسة.

## التشغيل محلياً

```bash
pip install -r requirements.txt
uvicorn app:app --reload --port 8000        # SQLite في مجلد المشروع
SEED_DEMO=1 DATA_DIR=/tmp/demo uvicorn app:app --port 8000   # ببيانات وهمية للتجربة
```

## حفظ البيانات بشكل دائم (مهم قبل إدخال الطلاب)

قرص خطة Render المجانية يُمسح عند كل إعادة تشغيل. الحل: قاعدة PostgreSQL خارجية مجانية ودائمة.

1. أنشئ حساباً مجانياً في [Neon](https://neon.tech) وأنشئ مشروعاً (المنطقة الأقرب: Frankfurt).
2. انسخ رابط الاتصال (يبدأ بـ `postgresql://`).
3. في Render ← الخدمة ← Environment: أضف `DATABASE_URL` بهذا الرابط، ثم احفظ.
4. بعد إعادة النشر: ادخل بحساب المدير ← الإدارة ← حالة النظام. يجب أن تظهر «قاعدة البيانات: PostgreSQL — الحفظ دائم».

كل شيء يُحفظ في القاعدة: الطلاب، الإحالات، الغياب، التوجيه، الانتظار، الجدول، المعلمون، والنسخ الاحتياطية.
النسخة اليومية التلقائية الساعة 2:00 ظهراً بتوقيت الرياض، وتُحفظ آخر 30 نسخة، ويمكن تنزيلها كملف.

## الجدول المدرسي

| البند | القاعدة |
| --- | --- |
| الدوام | الأحد والاثنين ٧ حصص · الثلاثاء والأربعاء والخميس ٦ حصص |
| استثناء | شعبة ٧ (ثاني ثانوي — إدارة الأعمال) ٥ حصص يوم الخميس |
| الشعب | أول ثانوي ١–٣ · ثاني ثانوي ٥–٦ وإدارة أعمال ٧ · ثالث ثانوي ٨–٩ وإدارة أعمال ١٠ (لا توجد شعبة ٤) |

- القواعد في `school_structure.json`، والتحقق في `timetable_rules.py`.
- الجدول المعتمد `school_timetable_saved.json` خط أحمر: مقفل ضد التعديل من الواجهة (`TIMETABLE_LOCK=1`).
- لاعتماد جدول مصحّح: يُستبدل الملف في المستودع بعد موافقة المدرسة، ويُطبَّق تلقائياً عند النشر.
- `python tools/verify_timetable.py` يعرض التغطية والمخالفات. وداخل النظام: الانتظار والجدول ← سلامة الجدول، وجدول الشعبة.

## متغيرات البيئة

| المتغير | الغرض |
| --- | --- |
| `DATABASE_URL` | قاعدة PostgreSQL الدائمة (موصى به بشدة) |
| `SECRET_KEY` | توقيع جلسات الدخول — إلزامي على الخادم |
| `TIMETABLE_LOCK` | `1` يقفل الجدول المعتمد (افتراضي)، `0` لفتحه مؤقتاً |
| `DATA_DIR` | مجلد SQLite إن لم تُستخدم PostgreSQL |
| `SEED_DEMO` | `1` بيانات وهمية للتجربة فقط |

| المعلمون | 1001–1022 | إحالة طالب · إحالاتي · جدولي · انتظاراتي |

## التصميم

- الهوية في `tailwind.config.js` (الأخضر الأساسي، الحجر والحبر، خط IBM Plex Sans Arabic).
- بعد أي تعديل على أصناف `index.html`: `bash tools/build_css.sh` لإعادة بناء `static/app.css`.

## الفحوصات

```bash
python tools/verify_timetable.py --strict
DATA_DIR=/tmp/t uvicorn app:app --port 8765 &
python tests/smoke_test.py http://127.0.0.1:8765        # 80 فحصاً: الدخول والصلاحيات والانتظار
python tests/persistence_test.py http://127.0.0.1:8765  # الحفظ والنسخ والاستعادة
```

تعمل تلقائياً على GitHub مع كل دفع إلى `main` (`.github/workflows/deploy.yml`). والنشر على Render تلقائي مع كل دفع عبر تطبيق Render على GitHub.
